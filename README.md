A high-end, interactive digital forensic dashboard designed to streamline *Open Source Intelligence (OSINT)* workflows. This project provides a curated collection of 15+ essential tools for digital investigators, journalists, and security researchers.

[*🌐 Live Demo View](https://rahmymohamed.github.io/OSINT-HUB/)] | [🐞 Report Bug](#) | [✨ Request Feature*](#)

---

## 🚀 Key Features

* *⚡ Real-time Filtering:* Instantly search through tools by name or category.
* *💎 Cyberpunk UI:* A professional, glassmorphic dashboard built for clarity and impact.
* *🛠️ Operational Guides:* Each tool comes with a "How to Use" instruction for immediate action.
* *📱 Fully Responsive:* Optimized for desktop, tablets, and mobile devices.

---

## 🛠️ Included Intelligence Categories

| Category | Description |
| :--- | :--- |
| *Infrastructure* | Mapping servers, IoT devices, and network vulnerabilities. |
| *Identity* | Hunting social media profiles and digital footprints. |
| *Forensics* | Analyzing metadata, reverse image searching, and verification. |
| *Geolocation* | Satellite imagery and shadow analysis for physical tracking. |

## 🖥️ Tech Stack

This project is built using pure frontend technologies for maximum speed and easy deployment:

* *HTML5* - Semantic structure.
* *CSS3* - Custom properties, Glassmorphism, and Grid/Flexbox.
* *JavaScript (ES6)* - Dynamic filtering and DOM manipulation.
* *Google Fonts* - Orbitron & Inter for a professional look.

## ⚙️ How to Use

1.  *Clone the Repository:*
    bash
    git clone [https://github.com/your-username/osint-intelligence-hub.git](https://github.com/your-username/osint-intelligence-hub.git)
    
2.  *Open the Dashboard:*
    Simply open the index.html file in any modern web browser.
3.  *Search & Explore:*
    Use the neon search bar to filter tools based on your investigation needs (e.g., type "Social" or "IP").
